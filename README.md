# Buenos-Aires-Apartment-Price-Prediction

This model was developed to help homebuyers determine an appropriate offer when purchasing a property. It predicts apartment transaction prices in USD in Buenos Aires City. To evaluate its effectiveness, the project uses an \(R^2\) score, which was 69%, and MAE and RMSE values were approximately 26% of the median apartment price. The project is limited to three models: Linear Regression, Lasso Regression, and Ridge Regression.

At the end two things were recommended:
1. Polynomial Features: Introduce polynomial features to capture potential nonlinear relationships and interactions between input variables while retaining a linear regression framework.
2. Nonlinear Models: Experiment with more complex models, such as Decision Trees, Random Forest, Gradient Boosting and XGBoost, to capture nonlinear patterns and potentially improve predictive performance.
